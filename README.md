# cloudops 🌨️⚙️📊
cloudops : | Cloud Operations | GKE, Stackdriver, Metrics, Logs, Monitoring, Dashboards, Alerts, IAC |


## Objectives
-  Deploy cluster & required resources using Terraform : make create
-  Perform validation : make validate
-  Reviewed the associated metrics in Cloud Monitoring
-  Observe Kubernetes Clusters using Kubernetes Engine Monitoring
-  Native Prometheus integration : Alerting policy (Prometheus mem alloc)
-  Perform Teardown (Clean-up) : make teardown


## Similar Skills Sets
- AWS : Amazon CloudWatch + AWS X-Ray
- Azure : Azure Monitor + Application Insights
